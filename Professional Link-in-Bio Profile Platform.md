## Executive Summary

***

Product Name: \[TBD - working name: ProfileLink / Biofolio]

A block-based professional profile builder that combines the simplicity of Linktree with the depth of a traditional resume. Users can mix and match modular content blocks, use intent-based presets, and apply visual templates to create shareable, mobile-first professional profiles optimized for career advancement or client acquisition.

Value Proposition:

> "The only platform that lets you build a resume-style profile with link-in-bio simplicity — optimized for getting hired or getting booked."

Target Users:

* Job seekers and career changers
* Freelancers, consultants, and coaches
* Creatives building portfolios
* Small business owners
* Students and recent graduates
* Corporate professionals building personal brands

## Problem Statement

***

### The Gap in Current Solutions

| User Need                         | Existing Solution     | Gap                                                      |
| --------------------------------- | --------------------- | -------------------------------------------------------- |
| Simple, shareable online presence | Linktree, Beacons     | Too casual, no resume depth, influencer-focused          |

## Product Description

***

### Core Concept

A modular, block-based profile builder where users assemble their ideal professional presence from a library of content blocks, choose from intent-based presets, and apply styling templates — all without coding.

### How It Works

┌─────────────┐     ┌─────────────┐     ┌─────────────┐

│   Select                    │     │   Customize           │     │   Publish                  │

│   Preset                    │ → │   Blocks                 │ → │   & Share                 │

└─────────────┘     └─────────────┘     └─────────────┘

  (2 min)                               (5-10 min)                          (instant)



### Block-Based Architecture

Users select from 24+ content blocks organized by category:

| Category   | Blocks                                                                    |
| ---------- | ------------------------------------------------------------------------- |
| Identity   | Hero, Tagline, Location, Availability Status                              |
| Content    | Bio, Rich Text, Video Intro, Links List, Embedded Media                   |
| Experience | Work History, Education, Certifications, Skills Tags, Tools I Use         |
| Commerce   | Service Cards, Product Grid, Booking Calendar, Testimonials, Lead Capture |
| Portfolio  | Image Gallery, Case Study, Video Showcase, Audio/Podcast                  |
| Social     | Social Icons, Newsletter Signup, Contact Form, Footer Branding            |

### Preset System

Five intent-based starting points:

| Preset     | Primary Goal    | Key Blocks Highlighted                           |
| ---------- | --------------- | ------------------------------------------------ |
| Job Seeker | Get hired       | Work History, Skills, Education, Certifications  |
| Freelancer | Get booked      | Services, Testimonials, Case Studies, Booking    |
| Creative   | Showcase work   | Portfolio Gallery, Case Studies, Skills          |
| Coach      | Build trust     | Video Intro, Services, Credentials, Testimonials |
| Student    | Land first role | Education, Projects, Skills, Open to Work tag    |

### Template System

Visual styling applied independently of content:

* Minimal — Clean, text-focused, fast-loading
* Professional — Corporate-friendly, polished
* Bold — Eye-catching, distinctive design
* Niche — Industry-specific (Developer, Writer, Coach styles)

## Technical Considerations

***

### Core Technology Decisions

┌─────────────────────────────────────────────────────┐

│  ALTERNATIVE: FULL STACK SPECIFICATION             │

├─────────────────────────────────────────────────────┤

│                                                     │

│  FRONTEND                                           │

│  ├── Framework: TanStack Start                     │

│  ├── Router: TanStack Router                       │

│  ├── Data: TanStack Query (built-in)              │

│  ├── UI: Tailwind CSS + shadcn/ui                 │

│  ├── DnD: dnd-kit                                  │

│  └── Animations: Framer Motion                    │

│                                                     │

│  BACKEND                                            │

│  └── Supabase (same as above)                      │

│                                                     │

│  DEPLOYMENT                                         │

│  └── Vercel                                         │

│                                                     │

└─────────────────────────────────────────────────────┘

| Component | Recommendation             | Rationale                                   |
| --------- | -------------------------- | ------------------------------------------- |
| Frontend  | Next.js + React            | SSR for SEO, responsive, component-based    |
| Styling   | Tailwind CSS               | Rapid development, consistent design system |
| Database  | PostgreSQL (Supabase/Neon) | Relational data for blocks, user profiles   |
| Auth      | Clerk or Supabase Auth     | Simpler than building from scratch          |
| Storage   | Cloudinary or S3           | Image/video handling for portfolios         |
| Hosting   | Vercel                     | Seamless Next.js deployment                 |
| Analytics | Custom + Plausible         | Privacy-focused, simpler than GA            |

### Key Technical Challenges

1. Drag-and-Drop Block Editor — Complex UI, consider libraries like dnd-kit
2. Real-time Preview — Must feel instant across mobile/desktop
3. Profile Performance — Must load fast despite media (lazy loading, CDNs)
4. SEO for Profiles — Each profile needs to be indexable
5. PDF Generation — Server-side rendering for resume export
