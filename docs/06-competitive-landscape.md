## Competitive Landscape

### Competitor Matrix

| Competitor  | Type                 | Strength                 | Weakness                         | Your Advantage               |
| ----------- | -------------------- | ------------------------ | -------------------------------- | ---------------------------- |
| Linktree    | Link-in-bio          | Brand, simplicity, scale | No resume depth, creator-focused | Resume/Career focus          |
| Beacons     | All-in-one creator   | Store + email + link     | Creator-focused, \$25/mo         | Career-optimized, lower cost |
| Carrd       | Single-page site     | \$19/yr, custom domain   | Manual setup, no viral loop      | Block system, presets        |
| Kickresume  | Resume builder       | AI writing, templates    | No link-in-bio, static           | Mobile-first, shareable      |
| LinkedIn    | Professional network | Scale, recruiting        | Not shareable, algorithm         | Direct share link, clean     |
| Squarespace | Full website         | Professional, complete   | Overkill, expensive              | Simplicity + depth hybrid    |

### Market Gaps You're Filling

1. Professional Link-in-Bio — No platform combines career depth with link-in-bio style
2. Booking-Native Profiles — Services/booking built into profile (not just links)
3. Network Effects — Viral loop built into every profile
4. Intent-Based Presets — Guided setup for different goals
5. Resume Export — Auto-generate PDF from profile data
