## Risks & Mitigation

| Risk                          | Likelihood | Mitigation                                          |
| ----------------------------- | ---------- | --------------------------------------------------- |
| Linktree adds resume features | High       | Move faster, own "professional" positioning         |
| Hard to differentiate         | Medium     | Focus on presets + career features, not just blocks |
| Network effect takes time     | Medium     | Seed with initial users, incentivize early sharing  |
| Monetization challenge        | Medium     | Start with generous free tier, prove value first    |
| SEO competition               | Low        | Long-term play, focus on product first              |
