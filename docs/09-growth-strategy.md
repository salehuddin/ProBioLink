## Growth Strategy

### Primary Growth Channels

| Channel               | Strategy                                     | Expected Impact                |
| --------------------- | -------------------------------------------- | ------------------------------ |
| Network Effects       | "Made with X" footer + "View other profiles" | Every share = 2-3 new users    |
| Referral Program      | Unlock themes/features for invites           | 20-30% of new users            |
| Content/SEO           | Template library, "how-to" guides            | Long-term organic traffic      |
| Creator Partnerships  | Free premium for influencers                 | Early traction, social proof   |
| Job Board Integration | "Apply with Profile" button                  | Partnership with ATS platforms |
| Template Sharing      | Users share profile links                    | Social proof, viral potential  |

### Viral Loop Design

User A shares profile

      ↓

Visitor sees profile + "Made with X" footer

      ↓

Visitor clicks other profile links in footer

      ↓

New visitor creates own profile

      ↓

Repeat



### Launch Sequence

| Phase            | Timeline    | Focus                                        |
| ---------------- | ----------- | -------------------------------------------- |
| Beta             | Months 1-2  | 50-100 users, iterate on product             |
| Public Launch    | Month 3     | Templates, content marketing, early adopters |
| Viral Activation | Months 4-6  | Network effects live, referral program       |
| Scale            | Months 7-12 | Paid acquisition, team/agency features       |
