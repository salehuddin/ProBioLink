## Target Market & Use Cases

### Primary User Segments

| Segment                 | Size Estimate | Pain Point                                                | Key Features Needed                       |
| ----------------------- | ------------- | --------------------------------------------------------- | ----------------------------------------- |
| Job Seekers             | Large         | ATS systems ghost resumes; need direct employer attention | Resume export, profile views, "Apply" CTA |
| Freelancers/Consultants | Medium-Large  | Scattered links; need unified booking                     | Services, booking, testimonials           |
| Creatives               | Medium        | Need visual showcase without full website                 | Portfolio gallery, video, case studies    |
| Small Business Owners   | Medium        | Need simple online presence                               | Contact form, product links, social proof |
| Coaches/Mentors         | Small-Medium  | Need credibility + booking                                | Credentials, testimonials, native booking |
| Students/Recent Grads   | Large         | No experience; need differentiation                       | Education focus, projects, skills         |
| Corporate Professionals | Medium        | Want personal brand outside LinkedIn                      | Professional look, custom domain          |

### Use Case Examples

Example 1: Product Manager Seeking Job

* Uses "Job Seeker" preset
* Highlights: Work achievements with metrics, skills, video intro
* Shares link in resume, email signature, LinkedIn
* Recruiter clicks → sees full profile → downloads resume → contacts

Example 2: Brand Consultant Getting Booked

* Uses "Freelancer" preset
* Highlights: Services with pricing, case studies with results, testimonials
* Shares link in Instagram bio, podcast show notes, speaking bios
* Prospect clicks → sees services → books consultation → converts
