## Feature Set

### MVP Features (Phase 1)

| Feature              | Description                                                   |
| -------------------- | ------------------------------------------------------------- |
| Block Editor         | Add, remove, reorder blocks via drag-and-drop                 |
| Preset Selection     | Choose from 5 intent-based starting points                    |
| Template Application | Select from 4 template categories                             |
| Profile Preview      | Real-time mobile/desktop preview                              |
| Custom URL           | [platformname.bio/username](http://platformname.bio/username) |
| Social Links         | Connect 10+ platforms (LinkedIn, GitHub, Twitter, etc.)       |
| Analytics Dashboard  | Profile views, link clicks, visitor source                    |
| PDF Resume Export    | Auto-generate resume from profile data                        |
| Embed Support        | Embed profile on external websites                            |

### Advanced Features (Phase 2)

| Feature             | Description                                     |
| ------------------- | ----------------------------------------------- |
| Custom Domain       | Connect personal domain (yourname.com)          |
| Native Booking      | Built-in calendar/scheduling (no external tool) |
| Service Packages    | Create tiered service offerings with pricing    |
| Lead Capture        | Email collection forms with incentives          |
| Password Protection | Gate specific sections                          |
| Multi-language      | Profile available in multiple languages         |
| Team Profiles       | Company-branded team member pages               |
| API Access          | Developers can build integrations               |

### Premium Features (Phase 3 / Monetization)

| Feature            | Description                                     |
| ------------------ | ----------------------------------------------- |
| Advanced Analytics | Demographics, conversion tracking               |
| A/B Testing        | Test different template/arrangement performance |
| White Label        | Remove platform branding                        |
| Priority Support   | Dedicated account management                    |
| Export Data        | Full data portability                           |
